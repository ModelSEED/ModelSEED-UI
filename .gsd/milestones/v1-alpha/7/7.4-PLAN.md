# Plan 7.4: Implement Model/Genome Detail Page (`/model/[...slug]`)

## Objective
Implement the Model/Genome detail page that responds to URLs matching `/model/*` (e.g., `/model/plantseed/plantseed/Alyrata-v1.0`). This ensures the "Model ID" links in the Reference Data (e.g. Public Plant Models) resolve correctly to exactly the same visual layout and data as the legacy application.

## Context
- `.gsd/ROADMAP.md`
- `app/(reference-data)/genomes/page.tsx` (Current source of the `/model/...` links)
- `external/ModelSEED-UI/app/views/data/model.html` (Legacy HTML template)
- `external/ModelSEED-UI/app/app.js` (Legacy routing for `/model{path:nonURIEncoded}`)
