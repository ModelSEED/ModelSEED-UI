# Phase 10 Plan 1: Solr Filter API Upgrade

## Objective
Upgrade `lib/api/biochem.ts` to seamlessly parse MUI's rich `FilterModel` (including operators like `>`, `<`, `between`, `contains`) into exact Solr Query syntax (`q` / `fq`).

## Scope
1. Define a `GridFilterModel` adapter inside `lib/api/biochem.ts` options.
2. Rewrite the query constructor in `buildSolrUrl` to parse `number` and `date` mathematical operators into Solr Range constraints (`field:[min TO max]`).
3. Maintain backward compatibility with the legacy `query` searching mechanism.
