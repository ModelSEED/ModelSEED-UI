# Plan 12.4: User Profile Display in Headers

## Objective
Display the currently signed-in user's username (extracted from the JWT or auth context) in the global `Header` and the `AppHeader`. This provides visual confirmation that the user is logged in and identifies active accounts.

- .gsd/ROADMAP.md

- components/layout/Header.tsx
- components/layout/AppHeader.tsx
