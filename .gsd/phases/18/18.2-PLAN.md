# Plan 18.2: Frontend End-to-End Testing for modelseed-api Flows

## Objective
Define and set up a front-end test plan that exercises the main authenticated user flows against the Poplar `modelseed-api` instance, including My Models, My Media, Build Model, and reference data, using real PATRIC accounts.

## Context
- `.gsd/SPEC.md`
- `.gsd/ROADMAP.md`
- `.gsd/phases/17/VERIFICATION.md`
- Frontend routes:
  - `app/(user-data)/my-models/page.tsx`
  - `app/(user-data)/myMedia/page.tsx`
  - `app/(build-model)/plant/page.tsx`
  - `app/(reference-data)/biochem/*`
  - `app/(reference-data)/genomes/*` and `list-media/page.tsx`
- Environment:
  - Next.js dev server on `http://localhost:3000`
  - modelseed-api on `http://poplar.cels.anl.gov:8000`
  - `NEXT_PUBLIC_USE_MODELSEED_API=true`
