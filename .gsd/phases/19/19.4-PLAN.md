# Phase 19.4 Plan: DataControlHeader Integration & Search Fix

## Problem
The DataControlHeader component exists but needs:
1. A clearer search affordance (including icon) with fully wired search callbacks.
2. Consistent integration across user data pages (My Models, My Media) so the header, not ad-hoc TextFields, controls filtering.
3. Integration across biochem reference data tabs (compounds, reactions, subsystems, media, plants) plus model-detail subtabs so tables share a single, predictable header pattern.
