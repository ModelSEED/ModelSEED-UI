# Plan 11.1: PlantSEED Maintenance Warning

## Objective
Implement a high-visibility warning banner across the PlantSEED toolset and temporarily disable the model building features for plant genomes, communicating the upcoming v3.0 release.

## Context
- `.gsd/SPEC.md`
- `.gsd/ROADMAP.md`
- `app/(build-model)/plant/page.tsx`
- `app/(reference-data)/genomes/page.tsx`

## Tasks

<task type="auto">
  <name>Add Maintenance Banner to PlantSEED Build Page</name>
  <files>
    - app/(build-model)/plant/page.tsx
  </files>
  <action>
    - Add a prominent, non-dismissible MUI `Alert` component at the top of the interface.
    - Message: "PlantSEED is being updated to version 3.0. Annotation and reconstruction services are temporarily offline for updates and will be restored shortly with our improved pipeline."
    - Disable the form/submit buttons for building new models to prevent usage of the legacy k-mer pipeline. You may remove or hide the submit functionality entirely depending on what's easiest, but the banner is required.
  </action>
  <verify>curl -s http://localhost:3000/plant | grep -i "temporarily offline"</verify>
  <done>The plant build page is visible but disabled, and the warning banner is displayed.</done>
</task>

<task type="auto">
  <name>Add Maintenance Banner to Genomes Reference Page</name>
  <files>
    - app/(reference-data)/genomes/page.tsx
  </files>
  <action>
    - Add the same warning banner (MUI `Alert`) at the top of the Genomes reference data page, alerting users that PlantSEED resources are undergoing updates to version 3.0.
    - Leave the table operational, just add the warning so users know things are transitioning.
  </action>
  <verify>curl -s http://localhost:3000/genomes | grep -i "PlantSEED is being updated"</verify>
  <done>The genomes reference data page displays the warning banner prominently.</done>
</task>

## Success Criteria
- [ ] Users visiting `/plant` see a clear maintenance warning and cannot invoke the legacy build pipeline.
- [ ] Users visiting `/genomes` see the maintenance warning but can still view public reference data.
