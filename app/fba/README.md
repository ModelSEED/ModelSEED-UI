# FBA Analysis View (`/fba`)

This directory displays **Flux Balance Analysis (FBA)** results. It is the primary tool for predicting the metabolic flux and growth of an organism under specific media conditions.

## 🔗 Legacy Path Mapping
- **AngularJS Origin**: `/fba`
- **Next.js Implementation**: `app/fba/[...path]/page.tsx`

## 📁 Content breakdown
- `page.tsx`: Currently a **Catch-all Stub**. Displays the FBA workspace path and an "Under Construction" banner.

### 🧪 Scientific context
- **Optimization**: Uses linear programming to maximize the Biomass objective.
- **Media**: Depends on the defined list of available nutrients (Metabolic Media).
- **Visualization**: Will eventually include flux maps and data tables (Phase 14).
