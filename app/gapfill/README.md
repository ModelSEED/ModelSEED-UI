# Gapfilling Results (`/gapfill`)

**Gapfilling** is the process of metabolic network reconstruction where missing reactions are identified and added to allow a model to simulate cell growth.

## 🔗 Legacy Path Mapping
- **AngularJS Origin**: `/gapfill`
- **Next.js Implementation**: `app/gapfill/[...path]/page.tsx`

## 📁 Content breakdown
- `page.tsx`: Currently a **Catch-all Stub**. Displays the gapfilling workspace path and an "Under Construction" banner.

### 🧪 Scientific importance
A genome-scale metabolic model (GEM) is often missing (or has gaps in) its metabolic network. Gapfilling resolves these missing steps to make the model "simulatable." Results in this directory typically show the specific reactions added to close these gaps.
