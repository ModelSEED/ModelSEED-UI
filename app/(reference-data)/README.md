# Reference Data Directory (`(reference-data)`)

This directory contains **Routes for Public Biological Data**, including Biochemistry (Reactions/Compounds) and Genomes.

## Biological Content

- **`biochem/`**: Biochemistry library including Compounds and Reactions (Solr-indexed).
- **`genomes/`**: Public genome repository (KBase-linked).
- **`list-media/`**: Public metabolic media directory.

## Key Files
- **`layout.tsx`**: Defines the layout shared by all biochemistry and reference data pages.

## Access Control
All routes within this directory are **publicly accessible**. They display high-quality, curated ModelSEED data that does not require an account to view.
