# Project Agents

This project uses **Get Shit Done (GSD)** methodology for autonomous development.

## Active Agents

- **Planner**: Handles `/plan`, `/roadmap`, and phase decomposition.
- **Executor**: Handles `/execute`, task implementation, and atomic commits.
- **Verifier**: Handles `/verify`, regression testing, and quality assurance.
- **Debugger**: Handles `/debug` and systematic issue resolution.

## Configuration

Custom skills and workflows are defined in the `.opencode/` directory.

### Slash Commands
- `/plan` - Strategic planning
- `/execute` - Wave-based execution
- `/verify` - Empirical validation
- `/debug` - Systematic debugging
- `/map` - Architecture mapping

For a full list of commands, run `/help`.
